How to export a Telegram chat as JSON

Last updated November 22, 2026. Steps checked against Telegram's official pages the same day.

Telegram lets you save a chat to your computer as HTML or as machine-readable JSON. The JSON file is the one you want if you plan to open the chat in a recap tool. The export runs in Telegram Desktop, not in the phone apps.

Export one chat from Telegram Desktop

Telegram's blog documents a per-chat export: open the menu in any chat and choose Export chat history. The data export schema also describes a full-account export from Settings, then Advanced, then Export Telegram data. For a year-in-review of one group, export that chat only.

  1. Install Telegram Desktop and sign in The export tool is in the official Telegram Desktop app on Windows, macOS, or Linux, not in the iPhone or Android apps. Install the latest version and sign in.
  2. Open the chat and choose Export chat history Open the group or private chat. Click the three-dot menu and choose Export chat history. Telegram's own blog also documents this per-chat path.
  3. Leave media off, and set the format to JSON Untick photos, videos, and other media if you only need the messages. A recap of who talked most does not need media and stays much smaller. Set Format to Machine-readable JSON. The HTML format will not work in Group Chat Wrapped.
  4. Export and keep Telegram open Choose a folder if you want, then click Export. Leave Telegram running until it finishes. The export folder usually contains a file named result.json, plus any media folders you included.

What result.json contains

Telegram's export schema says a single-chat export is represented in result.json as one chat object, including its messages. Media is stored in folders next to that file and referenced by relative paths. If you left media off, you still get the message text and timestamps, which is enough to count who talked most and when the group was busiest.

A full-account export can also include personal information, contacts, and other chats. If you made one of those by mistake, keep it private, or make a fresh per-chat export instead.

Common questions

Can I export from my phone?

Telegram documents the export tool in Telegram Desktop on a computer. We do not have official phone-app steps for a full JSON chat export, so use Desktop.

What is the difference between exporting one chat and exporting all data?

For one group, use Export chat history in that chat. To export more of your account, Telegram's data-export documentation says: in Telegram Desktop, go to Settings, then Advanced, then Export Telegram data. A full export is larger and can include account details you may not want to keep around. For a single recap, the per-chat export is enough.

Which file do I open?

Use result.json, or a ZIP of the export folder. Group Chat Wrapped does not read the HTML export (messages.html or export_results.html).

The export is taking a long time.

Media is usually what slows it down. Untick media and try again. Do not quit Telegram until the progress finishes.
