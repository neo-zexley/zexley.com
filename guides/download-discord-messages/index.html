How to download your Discord messages (data package) and see your year on Discord

Last updated November 22, 2026. Steps checked against Discord's official help the same day.

Discord's official way to get a copy of your messages is the data package. You request it from your settings, and Discord emails you a download link for a ZIP when it is ready. That can take a while. This page follows Discord's own help, then shows you how to turn the messages in the package into a private recap of your year.

Good to know first: the message files in a Discord data package contain only the messages you sent, not anyone else's. So a Discord recap is a personal recap of your own year, not a recap of a whole server or group.

Request your Discord data package

These steps follow Discord's help page about your data package. Discord's menus can change, and the wording differs a little between desktop and mobile.

  1. Open User Settings On desktop or in a browser, click the cogwheel in the bottom-left of Discord to open User Settings. On mobile, tap your avatar in the bottom-right corner, then tap the cogwheel in the upper-right corner to open Settings.
  2. Find the data request in Data & Privacy Open Data & Privacy. On desktop or in a browser, scroll to Request your data and press Request Data. On mobile, select Request all of my data.
  3. Choose what to include Discord shows a Submit Data Request window (or page, on mobile) where you select which data you want. Make sure your messages are included. Group Chat Wrapped only reads the message files.
  4. Submit the request and wait Press Request My Data. Discord shows a confirmation that you should receive your data package within 30 days, and it sends the package to the email address on your Discord account.
  5. Download the ZIP while the link works Discord says the download link stays active for 30 days. Download the ZIP and save it somewhere only you can open. Discord also says that disabling or deleting your account before you get the link cancels the request.

Discord's help page also says that if you have permanently lost access to your account, you can ask Discord about your data package through the contact listed on that page.

What is in the data package

Discord describes the package as a ZIP of JSON files with folders for your account, activity, messages, servers, and more. The account folder can include your email address, phone number, IP addresses, and payment history, so keep the whole ZIP private.

The Messages folder holds the messages you have sent, split into one folder per direct message, group DM, or server channel. Each folder is named with a channel ID, and a separate JSON file maps channel IDs to channel names. Discord says messages you deleted yourself are not included.

Why a Discord recap is about you

Because the package has only your own messages, a recap can show your busiest days and hours, the channels and DMs where you talked most, your words, emoji, and streaks. It cannot show who talked most in a server, or hand out group awards that need everyone's messages. Group Chat Wrapped gives Discord recaps personal badges instead.

Common questions

Can I get everyone's messages from a Discord server or group DM?

Not from the official data package. Discord says the Messages folder holds the messages you have sent. It does not include other people's messages, so Group Chat Wrapped makes a personal recap about you and cannot show who talked most in a server.

How long does the Discord data package take?

Discord says you should receive it within 30 days of the request. After it arrives, the download link stays active for 30 days.

Will deleted messages show up?

No. Discord says a message you delete yourself is no longer stored, so it will not be in your data package.

Does the recap count only 2026?

If the package has messages from 2026, the recap counts 2026 only and tells you how many older messages were left out. If it has none from 2026, it counts all of your messages and labels the recap all time.

Does Zexley see my data package?

No. Group Chat Wrapped opens the ZIP only in your browser and reads only the message files in its Messages folder. Your account details, activity, and payment files in the package are never opened, and nothing is uploaded.
