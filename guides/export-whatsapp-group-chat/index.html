How to export a WhatsApp group chat on iPhone and Android

Last updated November 22, 2026. Steps checked against WhatsApp's official help the same day.

WhatsApp lets you export a copy of a group chat that is on your phone. You get a text file (a ZIP on iPhone) that you can save, share, or drop into a recap tool. This page follows WhatsApp's own help, then explains what the file is good for and what it leaves out.

Before you start

  • You need to be a member of the group, with the chat open on the phone that holds the history.
  • Export only a chat you are part of, and treat the file as private. It contains other people's names and messages.
  • If Export chat is missing, check whether Restricted chat is on. WhatsApp says that when it is enabled, people in the chat cannot export it. In a group, only an admin can change that setting.

Export on iPhone

These steps match WhatsApp's iPhone help page for exporting chat history.

  1. Open the group Open the group chat in WhatsApp on your iPhone.
  2. Open Export chat Tap the group name at the top, then tap Export chat.
  3. Choose a media option If the chat contains media, choose With all media, With selected media, or Without media. For a recap of who talked most, Without media is enough and makes a much smaller file.
  4. Save the ZIP Choose where to send it. WhatsApp's examples are Message, Save to Files, or Notes. Save to Files keeps the ZIP on your phone.

WhatsApp says the iPhone export is a ZIP file, that view-once messages will not be exported, and that the file cannot be imported back into WhatsApp because it is a text file, not a backup.

Export on Android

These steps match WhatsApp's Android help page.

  1. Open the group Open the group chat in WhatsApp on your Android phone.
  2. Open Export chat Tap the menu (three dots), then More, then Export chat.
  3. Choose a media option Tap Without media or Include media. Without media is enough for a year-in-review recap. If you include media, WhatsApp says only the most recent media is added as attachments.
  4. Send or save the file Choose where to send it. WhatsApp's examples are Quick Share, Gmail, or Chat. Emailing it to yourself or saving it to Files or Drive is a reliable way to keep the text file.

WhatsApp says the export cannot be imported back into WhatsApp, because it is a text file and not a backup file.

What you get, and what is missing

The text file lists messages with a date, time, and sender name, as they appear on your phone. It is a copy of what your phone has, not a complete archive of the group's entire life:

  • History often starts around the day you joined, or around the last time you restored a backup.
  • View-once messages are not included in the iPhone export, according to WhatsApp.
  • If Restricted chat is on, you cannot export at all until an admin turns it off.

WhatsApp's current help for this feature is written for iPhone and Android. When we checked the Windows help page on November 22, 2026, WhatsApp said the feature was not available on that platform. Use the phone that holds the chat.

Common questions

Can any group member export the chat?

WhatsApp's export help uses the same steps for individual and group chats and does not say you have to be an admin. If you do not see Export chat, the group may have Restricted chat turned on. WhatsApp says group admins can enable Restricted chat, and while it is on, people in the chat cannot export it.

Does exporting notify the group?

WhatsApp's official export page does not say that other members are notified. We cannot promise how that might change, so treat the file as private either way.

Why does my export start later than I expected?

The export only holds the history that is on your phone. That often starts around the day you joined. View-once messages are not exported on iPhone, and the file cannot be imported back into WhatsApp because it is a text file, not a backup.

What file should I use for Group Chat Wrapped?

On iPhone, drop the ZIP, or unzip it and drop the _chat.txt inside. On Android, drop the .txt file, or a ZIP if that is what you saved. You do not need photos or videos for the recap.
